# RainFocus

> RainFocus is an enterprise event management and event marketing platform used by large B2B
> organizations to run conferences, roadshows, field-marketing programs, kickoffs and webinars from
> a single data-first system, anchored on a Global Attendee Profile. Its developer surface is a
> customer-provisioned Integration Suite: a RESTful API at api.rainfocus.com governed by named API
> Profiles, and RainFocus Nexus MCP Profiles, an OAuth-secured remote Model Context Protocol server
> at api.rainfocus.com/mcp/ that exposes live event data to AI agents.

RainFocus does not publish an llms.txt. This file is generated by API Evangelist from the public
RainFocus surface and from the artifacts in this repository. It is a third-party profile, not a
RainFocus document. Generated 2026-08-26.

## What an agent can and cannot do here

- There is a real, live, first-party remote MCP server: POST to https://api.rainfocus.com/mcp/
- It is OAuth-gated. An unauthenticated tools/list returns HTTP 401 "Access token not found in mcp
  request" with a WWW-Authenticate Bearer challenge carrying RFC 9728 resource_metadata.
- The authorization server is https://events.rainfocus.com/oidc. Discovery documents are public.
- Tool names and input schemas are NOT public. They require an authenticated introspection against
  a customer's provisioned MCP Profile.
- There is no OpenAPI, GraphQL SDL, AsyncAPI, WSDL or Protobuf contract published anywhere.
- There are no client SDKs in any public package registry and no public GitHub organization.
- MCP access is provisioned per customer in the RainFocus Integration Suite under
  Integration Suite > Active Profiles > MCP Profiles, and is scoped event by event.
- Per RainFocus's published announcement the MCP surface both reads (session capacity, check-in
  status, attendee profiles, exhibitor data, session records) and writes (closing registration,
  updating speaker details). No reversal operation or window is published for any write.
- Rate limits exist per the API terms but no number, window or response header is published.

## APIs

- [RainFocus Platform API](https://www.rainfocus.com/why-rainfocus/integrations/): RESTful
  integration API at https://api.rainfocus.com/api. Every request must name an apiProfile; omitting
  it returns HTTP 400 {"responseCode":"103","responseMessage":"Required parameter missing:
  apiProfile"}. Credentials are OAuth (Global) client ID and secret issued per API Profile.
- [RainFocus Nexus MCP Profiles](https://www.rainfocus.com/company/news-press/rainfocus-launches-ai-agent-connectivity-for-event-data-with-mcp-profiles/):
  remote MCP server at https://api.rainfocus.com/mcp/, announced 7 July 2026.
